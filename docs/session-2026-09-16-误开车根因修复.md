## 四、关键经验

1. **模板阈值必须多场景校准**：单场景自匹配 1.000 无意义；正样本要覆盖多头像背景/攻击红光/动画帧，负样本要全量扫描（含同族串扰带逐帧目检）。
2. **「看不见」≠「不存在」**：徽标不可见可能是面板遮挡/视图错误，判「无队列」必须先确认在地图视图（联盟旗帜可见）。
3. **`_find` 语义陷阱**：不匹配与未配置都返回 None，区分须用 `_rec.get`。
4. **UI 按钮语义要用实机点击验证**：同位置按钮在两个视图下 glyph 与语义都不同（进城/出城）。
5. `_find` 返回 None 时不可链式取 `.matched`。
