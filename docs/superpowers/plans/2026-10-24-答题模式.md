# 答题模式（quiz mode）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 myrok 里新增「答题模式」：自动进入《万国觉醒》知识问答活动，OCR 还原题干与四个选项，按「随包题库 → 大模型兜底 → 随机」作答，答完从绿色高亮反推正确答案写回学习题库，答到活动结束算一轮。

**Architecture:** 沿用现有分层。`core/quiz/` 是纯逻辑包（不 import Qt、不 import workers），输入是 OCR 文本块与 BGR 帧，输出是纯数据结构；`workers/quiz_sm.py` 只做「取帧 → 调纯函数 → 决定下一步」；`coordination/quiz_runtime.py` 继承 `BaseCoordinator`，把题库与 LLM 客户端持在 coordinator 上（SM 每轮重建不重读）。算法参考 `dati/ROK答题助手与题库/rok-quiz-helper/`，但**只搬算法，不搬它的进程模型**（它自带 while 循环与第二套 ADB 封装）。

**Tech Stack:** Python 3.14、pydantic v2、OpenCV（HSV 判据）、`difflib`（模糊匹配）、`urllib.request`（LLM，**不新增依赖**）、RapidOCR（项目已有的 `RapidOcrEngine`）。

**Spec:** `docs/superpowers/specs/2026-10-24-答题模式-design.md`

## Global Constraints

- **绝不抛异常**：状态机里任何失败都写成 `ctx["fail_reason"] = <常量>` 并走到 `END` 边。`WorkerRunner` 收到 step 异常时**不重建 SM**，会在同一状态退避重放，攒满 6 次直接停机（见 `workers/runner.py` 与 PROGRESS 已知问题 8/14）。
- **任何新失败原因都要有常数、有测试、有归属**：环境类必须进 `workers/runner.py` 的 `_ENV_FAIL_REASONS`（不计连续失败）；真失败**必须留在名单外**。`tests/unit/workers/test_runner.py::test_env_fail_reasons_cover_every_abort_reason` 是缺口哨兵，本计划要给它加 quiz 分支。
- **路径不许 CWD 相对**：只读资源走 `infra.app_paths.resource_dir()`（内部用 `resolve_asset()`），可写数据走 `user_dir()`。绿色包双击时 CWD 可能是 `C:\Windows\System32`。
- **fork 外部程序一律走 `infra/subproc.py`**：本模式不额外 fork 任何程序（ADB 走现有 `AdbHandleSource`）。
- **不吃新依赖**：LLM 用标准库 `urllib.request`；图像用已有的 `cv2`；模糊匹配用 `difflib`。
- **解析宁可不点，不要点错**：`parse_question()` 拿不到恰好 4 个选项就返回 `None`。
- **cv2 的 HSV 色相是 0–179**，不是 PIL 的 0–255。绿 = 42–77，红 = ≤11 或 ≥172，S/V ≥ 40。**直接把 PIL 的 60–110 抄过来会一行绿都数不出来。**
- **分辨率无关**：素材实测 2664×1200（静止帧）与 1280×576（视频），都不是 1080p。判据里不许出现绝对坐标；分列轴用 `frame_width / 2`，**不要用题干中心**。
- **文档只记字段作用，不记取值**：要看实际配了什么值直接读 `config.yaml`。
- **不动 `main` 上已有的未提交改动**：工作区很脏（约 30 个用户文件未提交）。每个 task 只 `git add` 自己列出的路径，**绝不 `git add -A`**。
- **不删任何图片/模板/标注**：本计划不删除任何既有资源；`templates/quiz/` 是新增目录。
- **`dati/` 是未入库的第三方素材**：只读取、不 import、不 `cd` 进去、不提交。读它的 Python 一律带 `-I`。
- 用 `.venv/Scripts/python.exe`（下面记作 `$PY`）；`tools/*.py` 的中文输出配 `-X utf8`；bash 双引号里不要出现反引号。
- 测试默认只跑相关子集；收尾跑一次 `$PY -m pytest tests/unit -q`。

```python
class NoRoleCharacterConfig(BaseModel):
    """无分工模式的角色（宝石 / 答题共用）。

    **刻意没有 role / target_levels / march_presets**：这两种模式一台模拟器
    一个号、流程固定，既没有分工也没有预设槽。把这些字段搬过来只会让
    「填了但不生效」变成可能——用户配了 role: leader 却什么都不发生，
    比字段不存在更难查。
    """

    id: str
    name: str = Field(min_length=1)


class NoRoleInstanceConfig(InstanceBase):
    characters: list[NoRoleCharacterConfig]

    @model_validator(mode="after")
    def _one_character(self):
        if len(self.characters) != 1:
            raise ValueError(
                f"Instance {self.id}: 该模式一台模拟器恰好 1 个角色"
                f"（收到 {len(self.characters)} 个）")
        return self
```

```python
class QuizLLMConfig(BaseModel):
    """答题模式的大模型兜底（OpenAI 兼容接口）。

    `api_key` 是明文落在 config.yaml 里的（绿色包里用户自己保管）；
    `enabled=False` 时**完全不发网络请求**，题库外直接随机。
    """

    enabled: bool = False
    base_url: str = "https://api.deepseek.com/v1"
    model: str = "deepseek-chat"
    api_key: str = ""
    timeout_s: float = Field(default=8.0, gt=0)


class QuizConfig(BaseModel):
    """答题模式的专属配置（spec §5）。

    **不继承 ModeConfig**：那是寨多多专属的 `instances: list[InstanceConfig]`
    （min_length=1 + leader/member 交叉校验），答题套上去会当场加载失败。
    与 GemConfig 一样直接继承 BaseModel，自己写 id 唯一性校验。

    字段取值只在这里校验上下界；**具体配几轮/几分钟不写进文档**，
    要看实际值直接读 config.yaml。
    """

    instances: list[QuizInstanceConfig] = Field(default_factory=list)
    max_rounds: int = Field(default=3, ge=1)              # 跑满这么多轮自动收工
    fuzzy_threshold: float = Field(default=0.72, ge=0.0, le=1.0)  # 题库模糊匹配阈值
    verify_delay: float = Field(default=1.2, ge=0.0)      # 点完选项后多久截图看绿色
    min_green_ratio: float = Field(default=0.55, ge=0.0, le=1.0)
    max_questions_per_round: int = Field(default=30, ge=1)
    round_cooldown_min: float = Field(default=10.0, ge=0.0)
    parse_retries: int = Field(default=2, ge=1)           # 同一题最多读几次再中止
    auto_click: bool = True                               # false = 只记日志不点击
    # 从地图点进答题活动页的**固定落点序列**（像素），真机探针
    # tools/quiz_entry_probe.py 测出来后填进来。空列表 = 只靠屏幕文字
    # （进入 / 习题演练 / 活动）找入口；找不到就报 quiz_entry_missing。
    entry_taps: list[tuple[int, int]] = Field(default_factory=list)
    llm: QuizLLMConfig = Field(default_factory=QuizLLMConfig)

    @model_validator(mode="after")
    def _checks(self):
        ids = [i.id for i in self.instances]
        if len(ids) != len(set(ids)):
            raise ValueError("quiz 实例 id 重复")
        char_ids = [c.id for i in self.instances for c in i.characters]
        if len(char_ids) != len(set(char_ids)):
            raise ValueError("quiz 角色 id 重复")
        return self
```

`src/rok_assistant/core/quiz/screen.py`（完整实现，**顺序就是判据优先级**）：

```python
"""屏幕解析：把 OCR 文本块还原成「题干 + A/B/C/D 四个选项」。

分辨率无关：全部判据用相对位置与块间关系，不出现任何绝对坐标。
素材实测有 2664×1200 与 1280×576 两种尺寸，都不是 1080p。

比参考实现严的地方（都是素材里暴露出来的坑）：
  * 分列轴 = **画面中线**，跨轴块整块丢掉（提示语/复活 toast 都横跨轴）
  * 丢「只有 1 个成员的行」（倒计时、剩余人数都是孤立行）
  * 必须恰好 2 行 × 每行 1 左 1 右，否则返回 None（宁可不点，不要点错）
"""
from __future__ import annotations

import re
from collections.abc import Sequence

from .models import LETTERS, ScreenQuestion, TextBlock

# 答题界面的标题词（活动页 / 复试页 / 习题演练页）
TITLE_KEYWORDS = ("国士无双", "国王无双", "习题演练", "知识问答", "复试", "初试")

# 按钮/界面文字，永远不是选项
UI_NOISE = frozenset({"放弃", "求助", "确定", "开始", "继续", "退出", "返回",
                      "关闭", "分享"})

# 界面上的动态文字（倒计时、人数、奖励……），一律不作为选项
NOISE_PATTERNS = ("剩余时间", "答题时间", "倒计时", "通过后可获", "暂入", "已答",
                  "积分", "排名", "宝石", "关卡", "观看", "复活", "求助")

# 活动页的入口候选，按优先级排列：真按钮 > 加大字号的卡片标题 > 地图上的活动图标
ENTRY_LABELS = ("进入", "习题演练", "活动")

_Q_RE = re.compile(r"^Q\s*(\d+)$", re.I)
_OPT_PREFIX_RE = re.compile(r"^\s*([ABCDabcd])[\.．、:：\s\)）]*\s*(.+)$")
_CJK_RE = re.compile(r"[一-鿿]")
# 纯数字/计数/时间码（`00:16 /01:06` 也算）：这类块不可能是选项
_NUMERIC_RE = re.compile(r"^[\d\s,，\.%\+\-/:：]+$")


def detect_quiz(blocks: Sequence[TextBlock]) -> bool:
    """当前屏幕是不是答题界面。

    活动页也会命中（标题里有「国士无双」）——所以**判定入口是否已进入
    答题界面要用 parse_question()，不是这个函数**。
    """
    texts = [text.strip() for _box, text, _conf in blocks]
    if any(k in " ".join(texts) for k in TITLE_KEYWORDS):
        return True
    return any(_Q_RE.match(t) for t in texts)


def _find_q_marker(blocks: Sequence[TextBlock]) -> int | None:
    for i, (_box, text, _conf) in enumerate(blocks):
        if _Q_RE.match(text.strip()):
            return i
    return None


def _pick_question_text(blocks: Sequence[TextBlock]) -> tuple[str, int]:
    """挑出题干与其底边 y（`q_bottom`）。挑不出返回 ("", 0)。"""
    marker_idx = _find_q_marker(blocks)
    if marker_idx is not None:
        mbox = blocks[marker_idx][0]
        line_h = max(mbox.y2 - mbox.y1, 1)
        first: tuple | None = None
        for i, (box, text, _conf) in enumerate(blocks):
            t = text.strip()
            if i == marker_idx or _OPT_PREFIX_RE.match(t):
                continue
            if not (box.y1 < mbox.y2 and box.y2 > mbox.y1):    # 与题号同一行
                continue
            if box.x1 < mbox.x2:                               # 必须在题号右侧
                continue
            if first is None or len(t) > len(first[1]):
                first = (box, t)
        if first is not None:
            fbox, ftext = first
            parts, bottom = [ftext], fbox.y2
            x_right = fbox.x2
            for (box, text, _conf) in blocks:
                t = text.strip()
                if _OPT_PREFIX_RE.match(t):
                    continue
                if not t or t in UI_NOISE or any(p in t for p in NOISE_PATTERNS):
                    continue
                # 续行：上一行底边往下 0.5~1.5 个行高
                if not (bottom - line_h * 0.5 <= box.y1 <= bottom + line_h * 1.5):
                    continue
                if box.x1 > x_right + line_h * 3:
                    continue
                parts.append(t)
                bottom = max(bottom, box.y2)
                x_right = max(x_right, box.x2)
            return "".join(parts), int(bottom)

    # 退化：含问号的最长块
    cands = [(box, text.strip()) for box, text, _conf in blocks
             if ("？" in text or "?" in text)
             and not _OPT_PREFIX_RE.match(text.strip())
             and text.strip() not in UI_NOISE
             and not any(p in text for p in NOISE_PATTERNS)]
    if not cands:
        return "", 0
    box, text = max(cands, key=lambda c: len(c[1]))
    return text, int(box.y2)


def _looks_like_option(text: str) -> bool:
    if _NUMERIC_RE.fullmatch(text):
        return False
    if _CJK_RE.search(text):
        return True
    return len(text) >= 3


def _is_option_candidate(box, text: str, q_bottom: int, midline: float) -> bool:
    t = text.strip()
    if not t or t in UI_NOISE:
        return False
    if any(p in t for p in NOISE_PATTERNS):
        return False
    if _Q_RE.match(t):
        return False
    if re.fullmatch(r"[ABCDabcd]", t):        # 孤立字母块（A/B/C/D 标记）
        return False
    if q_bottom and box.y1 < q_bottom:        # 题干上方（标题栏、HUD）
        return False
    if box.x1 < midline <= box.x2:            # 跨轴：提示语、toast、HUD 长行
        return False
    return _looks_like_option(t)


def _parse_by_letter(blocks: Sequence[TextBlock],
                     q_bottom: int) -> dict[str, tuple[str, str]]:
    """带 A/B/C/D 前缀的块：命中时以字母为准，几何只用来补齐缺失字母。"""
    out: dict[str, tuple[str, str]] = {}
    for box, text, _conf in blocks:
        m = _OPT_PREFIX_RE.match(text.strip())
        if m is None:
            continue
        if q_bottom and box.y1 < q_bottom:
            continue
        letter = m.group(1).upper()
        if letter in LETTERS and letter not in out:
            out[letter] = (m.group(2).strip(), box)
    return out


def _overlap(a, b) -> bool:
    return a.x1 < b.x2 and b.x1 < a.x2 and a.y1 < b.y2 and b.y1 < a.y2


def _parse_by_geometry(blocks: Sequence[TextBlock], q_bottom: int,
                       frame_width: int) -> dict[str, tuple[str, object]]:
    """按 2×2 排布指派字母。不满足「恰好 2 行、每行 1 左 1 右」就返回 {}。"""
    midline = frame_width / 2.0
    pool = [(box, text.strip()) for box, text, _conf in blocks
            if _is_option_candidate(box, text, q_bottom, midline)]
    if len(pool) < 4:
        return {}

    heights = sorted(b.y2 - b.y1 for b, _t in pool)
    tol = max(1.0, heights[len(heights) // 2] * 0.6)

    rows: list[list[tuple]] = []
    for item in sorted(pool, key=lambda p: p[0].y1):
        for row in rows:
            if abs(item[0].y1 - row[0][0].y1) <= tol:
                row.append(item)
                break
        else:
            rows.append([item])

    # 孤立行是 HUD（倒计时 / 剩余人数 / 弹幕计数），不是选项
    rows = [r for r in rows if len(r) >= 2]
    if len(rows) != 2:
        return {}

    out: dict[str, tuple[str, object]] = {}
    for r_idx, row in enumerate(rows):
        left = [p for p in row if p[0].x2 <= midline]
        right = [p for p in row if p[0].x1 >= midline]
        if len(left) != 1 or len(right) != 1:
            return {}
        out[LETTERS[r_idx * 2]] = (left[0][1], left[0][0])
        out[LETTERS[r_idx * 2 + 1]] = (right[0][1], right[0][0])

    boxes = [out[k][1] for k in LETTERS]
    for i in range(len(boxes)):
        for j in range(i + 1, len(boxes)):
            if _overlap(boxes[i], boxes[j]):
                return {}
    return out


def parse_question(blocks: Sequence[TextBlock],
                   frame_width: int) -> ScreenQuestion | None:
    """还原题干与四个选项；拿不到**恰好 4 个**选项就返回 None。

    `frame_width` 只用来算分列轴（`frame_width / 2`）——**不要**用题干中心，
    短题干的中心会落进左列选项的 x 区间，把真选项判成跨轴。
    """
    text, q_bottom = _pick_question_text(blocks)
    if not text:
        return None

    options = _parse_by_letter(blocks, q_bottom)
    if len(options) < 4:
        geo = _parse_by_geometry(blocks, q_bottom, frame_width)
        if len(options) >= 2:
            for letter in LETTERS:
                if letter not in options and letter in geo:
                    options[letter] = geo[letter]
        elif len(geo) == 4:
            options = geo
    if len(options) != 4:
        return None
    return ScreenQuestion(text=text,
                          options={letter: options[letter] for letter in LETTERS})


def find_quiz_entry(blocks: Sequence[TextBlock]) -> tuple[int, int] | None:
    """在活动页上找「进入答题」的点击点（返回像素中心）。

    优先级：`进入` 按钮 > 最大号的 `习题演练` 卡片标题 > 地图上的 `活动`
    图标。同一级里取置信度最高的块；没有任何候选就返回 None
    （调用方据此写 `quiz_entry_missing`，**不要**乱点）。
    """
    for label in ENTRY_LABELS:
        cands = [(box, conf) for box, text, conf in blocks if label in text.strip()]
        if not cands:
            continue
        if label == "习题演练":
            box = max(cands, key=lambda c: c[0].y2 - c[0].y1)[0]
        else:
            box = max(cands, key=lambda c: c[1])[0]
        return box.center()
    return None
```

```python
"""题库：随包只读权威库 + 运行时学习库。

**两个文件**：
  * 随包题库 `templates/quiz/quiz_bank.json`（只读，1076 条）
  * 学习结果 `user_dir()/quiz/learned.json`（可写，运行时新增/修正）

**合并规则**（防一次颜色误判污染权威答案）：
  * 随包条目权威：同题以随包答案为准，学习结果不得覆盖
  * 学习条目之间可以互相修正（后学覆盖先学）
  * 落盘用「临时文件 + os.replace」：崩溃不丢题、不产生半截文件
"""
from __future__ import annotations

import difflib
import json
import os
import re
import unicodedata
from dataclasses import dataclass
from pathlib import Path

from ...infra.logger import get_logger

logger = get_logger(__name__)

_QNO_RE = re.compile(r"^q\s*\d+\s*[.．、:：]?\s*", re.I)
# 标点/空白/装饰符：`\W` 在 str 模式下是 Unicode 感知的，CJK 与数字都保留
_STRIP_RE = re.compile(r"[\s\W_]+", re.UNICODE)


def normalize(text: str) -> str:
    """NFKC → 去题号前缀 → 去标点空白 → 小写。

    **数字必须保留**：`24小时` 与 `48小时` 不能归一成同一个值。
    """
    t = unicodedata.normalize("NFKC", text or "").strip()
    t = _QNO_RE.sub("", t)
    return _STRIP_RE.sub("", t).lower()


def similarity(a: str, b: str) -> float:
    """两个**已归一化**字符串的相似度 ∈ [0, 1]。

    `solver.py` 也用它把题库答案对齐到屏幕上的选项文本（OCR 会把
    `不败的复兴者` 读成 `不的复兴者`），所以是公开函数。
    """
    if a == b:
        return 1.0
    if not a or not b:
        return 0.0
    if a in b or b in a:
        # 互含子串时按长度比打折：短题被长题整个包含不等于同一道题
        return min(len(a), len(b)) / max(len(a), len(b))
    return difflib.SequenceMatcher(None, a, b).ratio()


@dataclass(frozen=True)
class BankHit:
    answer: str
    source: str        # "exact" | "fuzzy"
    score: float


class QuizBank:
    def __init__(self, shipped_path: Path, learned_path: Path):
        self._shipped_path = Path(shipped_path)
        self._learned_path = Path(learned_path)
        self._shipped: dict[str, str] = {}
        self._learned: dict[str, tuple[str, str]] = {}
        self._loaded = False

    # ---- 读 ----

    @property
    def size(self) -> int:
        return len(self._shipped) + len(self._learned)

    def load(self) -> None:
        self._shipped = {}
        for entry in self._read_list(self._shipped_path):
            key = normalize(entry["q"])
            if key:
                self._shipped.setdefault(key, entry["a"].strip())
        self._learned = {}
        for entry in self._read_list(self._learned_path):
            key = normalize(entry["q"])
            if key:
                self._learned[key] = (entry["q"].strip(), entry["a"].strip())
        self._loaded = True

    @staticmethod
    def _read_list(path: Path) -> list[dict]:
        """读 JSON 数组；文件缺失或损坏都**不抛**（答题不能被题库拖挂）。"""
        if not Path(path).is_file():
            return []
        try:
            data = json.loads(Path(path).read_text(encoding="utf-8"))
        except (OSError, ValueError) as exc:
            logger.warning("[题库] 读不了 %s：%s", path, exc)
            return []
        if not isinstance(data, list):
            logger.warning("[题库] %s 不是 JSON 数组", path)
            return []
        return [e for e in data
                if isinstance(e, dict)
                and isinstance(e.get("q"), str) and e["q"].strip()
                and isinstance(e.get("a"), str) and e["a"].strip()]

    def lookup(self, question: str, threshold: float = 0.72) -> BankHit | None:
        if not self._loaded:
            self.load()
        key = normalize(question)
        if not key:
            return None
        if key in self._shipped:
            return BankHit(self._shipped[key], "exact", 1.0)
        if key in self._learned:
            return BankHit(self._learned[key][1], "exact", 1.0)

        best: BankHit | None = None
        for table in (self._shipped, {k: v[1] for k, v in self._learned.items()}):
            for other, answer in table.items():
                score = similarity(key, other)
                if best is None or score > best.score:
                    best = BankHit(answer, "fuzzy", score)
        if best is not None and best.score >= threshold:
            return best
        return None

    # ---- 写 ----

    def learn(self, question: str, answer: str) -> bool:
        """把「画面判定出来的正确答案」写进学习库。

        返回 True 表示内存里的答案变了（随包条目、无变化、写盘失败都返回 False）。
        **写盘失败不抛**：本次会话内仍可用，只是丢了持久化。
        """
        if not self._loaded:
            self.load()
        key = normalize(question)
        answer = (answer or "").strip()
        if not key or not answer:
            return False
        if key in self._shipped:
            logger.info("[题库] 随包条目权威，忽略学习结果：%s", question)
            return False
        prev = self._learned.get(key)
        if prev is not None and normalize(prev[1]) == normalize(answer):
            return False
        self._learned[key] = (question.strip(), answer)
        self._write_learned()
        return True

    def _write_learned(self) -> None:
        rows = [{"q": q, "a": a, "source": "learned"}
                for q, a in self._learned.values()]
        tmp = self._learned_path.with_name(self._learned_path.name + ".tmp")
        try:
            self._learned_path.parent.mkdir(parents=True, exist_ok=True)
            tmp.write_text(json.dumps(rows, ensure_ascii=False, indent=1) + "\n",
                           encoding="utf-8")
            os.replace(tmp, self._learned_path)
        except OSError as exc:
            logger.warning("[题库] 学习结果写入失败（本次会话内仍生效）：%s", exc)
            try:
                tmp.unlink(missing_ok=True)
            except OSError:
                pass
```

```python
"""绿色 = 正确答案：判据来自素材实测（正确项 0.97~1.00，噪声块 0.35~0.36）。

**色相刻度是 cv2 的 0-179**。参考实现用 PIL 的 0-255（绿 60~110），
直接抄过来会落到青色区间，一行绿都数不出来——这里第一条用例就是它的哨兵。
"""
import numpy as np
import pytest

from rok_assistant.core.quiz.verify import green_ratio, pick_correct_option
from rok_assistant.core.recognizer import BBox

GREEN = (0, 200, 0)       # BGR：cv2 H≈60，S/V 都够
RED = (0, 0, 200)         # BGR：cv2 H≈0
GRAY = (128, 128, 128)    # S=0：被饱和度门槛排除

BOXES = {
    "A": BBox(10, 10, 50, 30),
    "B": BBox(60, 10, 100, 30),
    "C": BBox(10, 40, 50, 60),
    "D": BBox(60, 40, 100, 60),
}


def _frame(fills: dict[str, tuple[int, int, int]]) -> np.ndarray:
    frame = np.full((80, 120, 3), 40, dtype=np.uint8)
    for letter, color in fills.items():
        b = BOXES[letter]
        frame[b.y1:b.y2, b.x1:b.x2] = color
    return frame


def test_cv2_hue_scale_counts_green():
    """49..77 之外的色相不该被算成绿（PIL 的 60 在这里是青色）。"""
    assert green_ratio(_frame({"A": GREEN}), BOXES["A"]) == pytest.approx(1.0)
    assert green_ratio(_frame({"A": (200, 200, 0)}), BOXES["A"]) == pytest.approx(0.0)


def test_picks_the_green_option_regardless_of_the_clicked_one():
    frame = _frame({"A": GRAY, "B": GREEN, "C": RED, "D": GRAY})
    assert pick_correct_option(frame, BOXES) == "B"


def test_all_gray_returns_none_and_learns_nothing():
    assert pick_correct_option(_frame({k: GRAY for k in BOXES}), BOXES) is None


def test_red_is_not_green():
    """答错时所选项变红、正确项仍是绿：绝不能把红色当成正确答案。"""
    frame = _frame({"A": RED, "B": GRAY, "C": GRAY, "D": GRAY})
    assert pick_correct_option(frame, BOXES) is None


def test_half_green_is_below_the_default_threshold():
    frame = _frame({"A": GRAY, "B": GREEN, "C": GRAY, "D": GRAY})
    b = BOXES["B"]
    frame[b.y1:b.y1 + 10, b.x1:b.x2] = GRAY          # 只剩一半绿
    assert green_ratio(frame, b) == pytest.approx(0.5)
    assert pick_correct_option(frame, BOXES) is None
```

```python
"""答完后「绿色 = 正确答案」的判定。

答对时所选项变绿；答错时所选项变红、正确项仍是绿——所以**答对答错都能
学到**答案（spec §4.3）。

用 cv2 而不是 PIL：项目已有 cv2，且 BBox 本来就是像素坐标。**色相刻度
必须换算**：PIL 的 H∈[0,255]（绿≈85），cv2 的 H∈[0,179]（绿 42~77）。
先在 BGR 空间缩采样再转 HSV——直接缩 HSV 会因插值产生伪色相。
"""
from __future__ import annotations

from collections.abc import Mapping

import cv2
import numpy as np

from ..recognizer import BBox

GREEN_LO, GREEN_HI = 42, 77          # cv2 色相
RED_HI, RED_LO = 11, 172             # 红 = H≤11 或 H≥172
SAT_MIN, VAL_MIN = 40, 40
# 素材实测：正确项 0.97/0.98/1.00，唯一的非选项绿色块（`日程`）0.35~0.36。
# 0.55 落在两者之间，留了两倍余量；参考实现的 0.35 太贴噪声底。
DEFAULT_MIN_RATIO = 0.55


def _ratios(frame: np.ndarray, box: BBox) -> tuple[float, float]:
    h, w = frame.shape[:2]
    x1, y1 = max(0, box.x1), max(0, box.y1)
    x2, y2 = min(w, box.x2), min(h, box.y2)
    if x2 <= x1 or y2 <= y1:
        return 0.0, 0.0
    crop = frame[y1:y2, x1:x2]
    ch, cw = crop.shape[:2]
    crop = crop[::max(1, ch // 60), ::max(1, cw // 120)]   # 先在 BGR 空间缩采样
    hsv = cv2.cvtColor(crop, cv2.COLOR_BGR2HSV)
    hue, sat, val = hsv[:, :, 0], hsv[:, :, 1], hsv[:, :, 2]
    valid = (sat >= SAT_MIN) & (val >= VAL_MIN)
    total = hue.size
    if not total:
        return 0.0, 0.0
    green = ((hue >= GREEN_LO) & (hue <= GREEN_HI) & valid).sum() / total
    red = (((hue <= RED_HI) | (hue >= RED_LO)) & valid).sum() / total
    return float(green), float(red)


def green_ratio(frame: np.ndarray, box: BBox, *,
                sat_min: int = SAT_MIN, val_min: int = VAL_MIN) -> float:
    """box 内绿色像素占比。`sat_min` / `val_min` 只为测试与外层调参保留。"""
    return _ratios(frame, box)[0]


def red_ratio(frame: np.ndarray, box: BBox, *,
              sat_min: int = SAT_MIN, val_min: int = VAL_MIN) -> float:
    return _ratios(frame, box)[1]


def pick_correct_option(frame: np.ndarray,
                        boxes: Mapping[str, BBox],
                        *, min_ratio: float = DEFAULT_MIN_RATIO) -> str | None:
    """返回「绿色高亮」的选项字母；没有合格项返回 None（**不猜**）。"""
    scored: list[tuple[float, str]] = []
    for letter, box in boxes.items():
        green, red = _ratios(frame, box)
        if green >= min_ratio and green > red:
            scored.append((green, letter))
    if not scored:
        return None
    scored.sort(key=lambda s: (-s[0], s[1]))     # 绿色占比最大；同分按字母
    return scored[0][1]
```

```python
"""大模型兜底：OpenAI 兼容的 /chat/completions，一次 POST。

**永不抛**：网络错、超时、返回体不合规一律返回 None，由 `Solver` 退到
随机。答题线程上抛异常会把一次「这题不会」升级成 WorkerRunner 的
连续失败（见 Global Constraints）。

不引 requests / openai SDK：只有一次 POST，urllib 够用；绿色包里少一个
依赖就少一类装不上的环境。
"""
from __future__ import annotations

import json
import urllib.request
from collections.abc import Mapping

from ...infra.logger import get_logger

logger = get_logger(__name__)

_SYSTEM = ("你是《万国觉醒》答题活动的答题器。只输出一个选项字母"
           "（A、B、C 或 D），不要解释，不要输出其他任何字符。")
_MAX_TOKENS = 8


class LLMClient:
    def __init__(self, *, base_url: str, model: str, api_key: str,
                 timeout_s: float = 8.0, enabled: bool = True, opener=None):
        self._base_url = (base_url or "").rstrip("/")
        self._model = model or ""
        self._api_key = api_key or ""
        self._timeout = float(timeout_s)
        self._enabled = bool(enabled)
        # opener 注入点：单测用假 opener，生产用 urllib.request.urlopen
        self._opener = opener if opener is not None else urllib.request.urlopen

    def choose(self, question: str, options: Mapping[str, str]) -> str | None:
        """让模型从 options 里选一个字母；任何问题都返回 None。"""
        if not (self._enabled and self._api_key and self._base_url and self._model):
            return None
        if not options:
            return None
        lines = [f"{letter}. {text}" for letter, text in sorted(options.items())]
        body = {
            "model": self._model,
            "temperature": 0,
            "max_tokens": _MAX_TOKENS,
            "messages": [
                {"role": "system", "content": _SYSTEM},
                {"role": "user",
                 "content": f"题目：{question}\n" + "\n".join(lines)},
            ],
        }
        req = urllib.request.Request(
            self._base_url + "/chat/completions",
            data=json.dumps(body).encode("utf-8"),
            headers={"Content-Type": "application/json",
                     "Authorization": f"Bearer {self._api_key}"},
            method="POST")
        try:
            with self._opener(req, timeout=self._timeout) as resp:
                payload = json.loads(resp.read().decode("utf-8"))
            content = payload["choices"][0]["message"]["content"]
        except (OSError, ValueError, KeyError, IndexError, TypeError) as exc:
            # OSError 覆盖 URLError/HTTPError/超时；ValueError 覆盖 JSON 坏掉
            logger.warning("[答题] 大模型兜底失败（本题退到随机）：%s", exc)
            return None
        letter = _extract_letter(content, options)
        if letter is None:
            logger.warning("[答题] 大模型回答无法映射到选项：%r", content)
        return letter


def _extract_letter(content: str, options: Mapping[str, str]) -> str | None:
    """从模型答复里取选项字母。先找字母，再退到「答复里唯一包含的选项文本」。"""
    text = (content or "").strip()
    for ch in text[:16]:
        up = ch.upper()
        if up in options:
            return up
    hits = [letter for letter, opt in options.items()
            if opt and opt in text]
    return hits[0] if len(hits) == 1 else None
```

`src/rok_assistant/core/quiz/solver.py`：

```python
"""三级作答决策：题库精确 → 题库模糊 → 大模型 → 随机。

`source` 会写进日志与验收输出，**是排查「为什么答错」的第一判据**：
bank 答错是题库脏了，llm 答错是模型不会，random 答错是两腿都没兜住。
"""
from __future__ import annotations

import random
from collections.abc import Sequence

from ...infra.logger import get_logger
from .bank import QuizBank, normalize, similarity
from .models import LETTERS, Decision, ScreenQuestion

logger = get_logger(__name__)


class Solver:
    def __init__(self, bank: QuizBank, llm=None, *,
                 fuzzy_threshold: float = 0.72,
                 answer_threshold: float = 0.6,
                 rng: random.Random | None = None):
        self._bank = bank
        self._llm = llm
        self._fuzzy_threshold = float(fuzzy_threshold)
        self._answer_threshold = float(answer_threshold)
        self._rng = rng if rng is not None else random.Random()

    def answer(self, question: ScreenQuestion) -> Decision | None:
        """给一道题一个决策；四选项不齐时返回 None（**不猜**）。"""
        letters = [l for l in LETTERS if l in question.options]
        if not letters:
            return None

        hit = self._bank.lookup(question.text, threshold=self._fuzzy_threshold)
        if hit is not None:
            letter = self._match_answer(hit.answer, question)
            if letter is not None:
                return Decision(letter, question.options[letter][0], "bank")
            logger.info("[答题] 题库答案 %r 对不上屏幕上的任何选项，"
                        "继续走兜底", hit.answer)

        if self._llm is not None:
            letter = self._llm.choose(question.text, question.option_texts())
            if letter in question.options:
                return Decision(letter, question.options[letter][0], "llm")

        letter = self._rng.choice(letters)
        return Decision(letter, question.options[letter][0], "random")

    def _match_answer(self, answer: str, question: ScreenQuestion) -> str | None:
        """题库/模型的答案文本 → 屏幕上的选项字母。

        先精确（归一化后相等），再按相似度取最高且过 `answer_threshold`
        的那个。四条选项里唯一命中才算——两个都像就放弃，绝不硬点。
        """
        key = normalize(answer)
        if not key:
            return None
        exact = [l for l, (text, _box) in question.options.items()
                 if normalize(text) == key]
        if len(exact) == 1:
            return exact[0]
        best_letter, best_score = None, 0.0
        for letter, (text, _box) in question.options.items():
            score = similarity(key, normalize(text))
            if score > best_score:
                best_letter, best_score = letter, score
        if best_letter is not None and best_score >= self._answer_threshold:
            return best_letter
        return None
```

> 注意：`Sequence` 没用到就别 import（上面那行 import 只留 `random`）。

```python
class _Clock:
    def __init__(self):
        self.now = 1000.0

    def __call__(self):
        return self.now

    def advance(self, dt=1.0):
        self.now += dt


class ScriptedHandle:
    """按顺序返回预置帧；用完后一直返回最后一帧。"""

    def __init__(self, frames):
        self._frames = list(frames)
        self._i = 0
        self.clicks = []

    def capture(self):
        frame = self._frames[min(self._i, len(self._frames) - 1)]
        self._i += 1
        return frame

    def click(self, x, y, anchor=None, rapid=False):
        self.clicks.append((int(x), int(y), anchor))

    def is_alive(self):
        return True


class FrameOcr:
    """帧对象 → OCR 块。同一帧永远读到同样的块（不按调用次数排队，稳）。"""

    def __init__(self, table):
        self._table = table

    def detect_text(self, frame):
        return list(self._table[id(frame)])


def _frame(blocks, green=None, w=W, h=H):
    frame = np.zeros((h, w, 3), dtype=np.uint8)
    if green is not None:
        box = parse_question(blocks, w).options[green][1]
        frame[box.y1:box.y2, box.x1:box.x2] = (0, 200, 0)
    return frame


def _bank(tmp_path) -> QuizBank:

    shipped.write_text(json.dumps(SHIPPED, ensure_ascii=False), encoding="utf-8")
    bank = QuizBank(shipped_path=shipped, learned_path=tmp_path / "learned.json")

def _make(tmp_path, script, *, bank=None, solver=None, **kw):
    """script: [(blocks, green_letter | None), ...] → (sm, handle, clock, bank)"""
    frames = [_frame(b, g) for b, g in script]
    table = {id(f): b for f, (b, _g) in zip(frames, script)}
    handle = ScriptedHandle(frames)
    clock = _Clock()
    bank = bank or _bank(tmp_path)
    solver = solver or Solver(bank, rng=random.Random(0))
    sm = QuizStateMachine(handle, FrameOcr(table), bank, solver,
                          clock=clock, sleeper=clock.advance,
                          rng=random.Random(0), **kw)
    return sm, handle, clock, bank


def _drive(sm, clock, max_steps=400, dt=1.0):
    for _ in range(max_steps):
        if sm.is_terminal():
            return
        clock.advance(dt)
        sm.step()
    raise AssertionError(f"没在 {max_steps} 步内结束（当前 {sm.current}）")


def _letter_of(blocks, click) -> str:

            return letter
    raise AssertionError(f"点击点 {click[:2]} 不落在任何选项上")
```

```python
"""答题模式状态机（spec docs/superpowers/specs/2026-10-24-答题模式-design.md §6/§9）。

一轮 = 收拾画面 → 进答题活动 → 逐题「读题 → 作答 → 验绿 → 学习 → 等翻页」
→ 活动结束 → 冷却。**答到活动结束算一轮**（用户 2026-10-24 拍板）。

**本模块绝不抛异常**：所有失败都写成 `ctx["fail_reason"] = <常量>` + END 边。
抛异常会让 WorkerRunner 在同一状态退避重放，攒满 6 次直接停机——一次
「这题读不出来」不该升级成停机。

**等待一律不 sleep**：用 `_not_before[状态]` + `step()` 提前返回（与
gem_sm 的 WAIT、either_sm 的 WAIT_RETURN 同一套路），否则用户点 Stop
要等完整段冷却才 join 得上。
"""
from __future__ import annotations

import time

from ..core.quiz.bank import QuizBank, normalize
from ..core.quiz.models import ScreenQuestion
from ..core.quiz.screen import detect_quiz, find_quiz_entry, parse_question
from ..core.quiz.solver import Solver
from ..core.quiz.verify import pick_correct_option
from ..infra.logger import get_logger
from .state_machine import NORMALIZE_STUCK_REASON, StateMachine

logger = get_logger(__name__)

# ---- 失败原因常量（runner._ENV_FAIL_REASONS 按值对齐，见哨兵用例）----

# 环境类：不计入连续失败
QUIZ_ENTRY_MISSING_REASON = "quiz_entry_missing"   # 找不到答题入口 / 活动没开
QUIZ_SCREEN_LOST_REASON = "quiz_screen_lost"       # 画面被弹窗/断线盖住
QUIZ_PARSE_FAILED_REASON = "quiz_parse_failed"     # 一题都没答就连续读不出
# 真失败：计入连续失败。点了选项、画面却停在原题——这不是环境问题，
# 是「这票没被受理」（spec §6 的反例）。
ANSWER_NOT_ACCEPTED_REASON = "answer_not_accepted"

_NAV_MAX = 4              # 进活动最多点几拍
_NORMALIZE_ATTEMPTS = 5
_NAV_SETTLE = 1.5         # 点完入口/落点后等动画
_PARSE_INTERVAL = 1.0     # 读不出题时的重读间隔
_ADVANCE_INTERVAL = 1.2   # 答完一题后等翻页的轮询间隔
_ADVANCE_WAIT_MAX = 4     # 同一题最多再看几眼才判「没翻页」

# 归一化时要收掉的残留面板（与 gem_sm 同一套落点，理由见那边注释）
_FORM_CLOSE_XY = (1716, 69)
_WAR_CLOSE_XY = (1671, 64)
_QUEUE_COLLAPSE_XY = (1550, 320)


class QuizStateMachine(StateMachine):
    def __init__(self, handle_source, ocr, bank: QuizBank, solver: Solver, *,
                 recognizers=None, verify_delay: float = 1.2,
                 min_green_ratio: float = 0.55,
                 max_questions_per_round: int = 30,
                 round_cooldown_min: float = 10.0,
                 parse_retries: int = 2, entry_taps=None,
                 auto_click: bool = True, char_id: str = "?",
                 human=None, clock=time.time, sleeper=time.sleep, rng=None):
        self._handle = handle_source
        self._ocr = ocr
        self._rec = recognizers or {}
        self._bank = bank
        self._solver = solver
        self._verify_delay = float(verify_delay)
        self._min_green_ratio = float(min_green_ratio)
        self._max_questions = int(max_questions_per_round)
        self._cooldown_min = float(round_cooldown_min)
        self._parse_retries = max(1, int(parse_retries))
        self._entry_taps = [tuple(int(v) for v in tap)
                            for tap in (entry_taps or [])]
        self._auto_click = bool(auto_click)
        self._char_id = char_id
        self._clock = clock
        self._sleep = sleeper
        # 各状态的「最早可再跑」时刻：等待靠它实现，**不阻塞线程**
        self._not_before: dict[str, float] = {}
        self._pending_question: ScreenQuestion | None = None
        self._answered_key = ""       # 上一题的归一化题干（判「有没有翻页」）
        self._answered = 0
        self._read_waits = 0
        self._advance_waits = 0
        self._nav_steps = 0
        super().__init__(initial="IDLE", human=human)
        self.last_image = None

    # ---- 转移表 ----

    def _setup(self):
        self.add_transition("IDLE", "NORMALIZE", self._normalize_view)
        self.add_transition("NORMALIZE", "END", self._abort_round,
                            guard=lambda ctx: ctx.get("fail_reason")
                            == NORMALIZE_STUCK_REASON)
        self.add_transition("NORMALIZE", "OPEN_QUIZ", self._reset_nav)

        # 入口导航：END（找不到入口）→ 自环（继续点）→ READ（进得去）
        self.add_transition("OPEN_QUIZ", "END", self._abort_round,
                            guard=lambda ctx: ctx.get("fail_reason")
                            == QUIZ_ENTRY_MISSING_REASON)
        self.add_transition("OPEN_QUIZ", "OPEN_QUIZ", self._open_quiz_step,
                            guard=lambda ctx: ctx.get("in_quiz") is False)
        self.add_transition("OPEN_QUIZ", "READ", lambda ctx: None)

        # 读题：中止边必须最先注册
        self.add_transition("READ", "END", self._abort_round,
                            guard=lambda ctx: ctx.get("fail_reason")
                            in (QUIZ_SCREEN_LOST_REASON, QUIZ_PARSE_FAILED_REASON))
        self.add_transition("READ", "COOLDOWN", self._enter_cooldown,
                            guard=lambda ctx: ctx.get("round_over") is True)
        self.add_transition("READ", "READ", lambda ctx: None,
                            guard=lambda ctx: ctx.get("parse_verdict") == "retry")
        self.add_transition("READ", "ANSWER", self._choose)

        self.add_transition("ANSWER", "END", self._abort_round,
                            guard=lambda ctx: ctx.get("fail_reason") is not None)
        # 半自动（auto_click=false）：给完建议就收本轮，不能等一个不存在的点击
        self.add_transition("ANSWER", "COOLDOWN", self._enter_cooldown,
                            guard=lambda ctx: ctx.get("semi_auto") is True)
        self.add_transition("ANSWER", "VERIFY", self._verify)

        self.add_transition("VERIFY", "LEARN", self._learn)
        self.add_transition("LEARN", "ADVANCE", self._advance)

        # 翻页：真失败边最先，其次前进/收轮，最后是无 guard 的等待自环
        self.add_transition("ADVANCE", "END", self._abort_round,
                            guard=lambda ctx: ctx.get("fail_reason")
                            == ANSWER_NOT_ACCEPTED_REASON)
        self.add_transition("ADVANCE", "READ", self._enter_next,
                            guard=lambda ctx: ctx.get("next_question") is True)
        self.add_transition("ADVANCE", "COOLDOWN", self._enter_cooldown,
                            guard=lambda ctx: ctx.get("round_over") is True)
        self.add_transition("ADVANCE", "ADVANCE", lambda ctx: None)

        self.add_transition("COOLDOWN", "END", lambda ctx: None)

    # ---- step 覆写：所有等待都是「看时钟」，不是 sleep ----

    def step(self, context: dict | None = None) -> None:
        if self._clock() < self._not_before.get(self.current, 0.0):
            return
        super().step(context)

    def is_terminal(self) -> bool:
        return self.current == "END"

    def _wait_here(self, state: str, delay: float) -> None:
        self._not_before[state] = self._clock() + max(0.0, delay)

    # ---- 收尾出口 ----

    def _abort_round(self, ctx):
        logger.warning("[答题 %s] 本轮中止：%s", self._char_id,
                       ctx.get("fail_reason"))

    def _enter_cooldown(self, ctx):
        why = ctx.get("cooldown_why")
        logger.info("[答题 %s] 本轮结束（答了 %s 题）%s", self._char_id,
                    self._answered, f"：{why}" if why else "")
        self._wait_here("COOLDOWN", self._cooldown_min * 60.0)

    # ---- IDLE → NORMALIZE ----

    def _normalize_view(self, ctx):
        """收拾到「地图视图」或「答题/活动页」。

        与宝石模式的区别：**答题页也算归一化成功**。硬把画面收成地图会把
        已经打开的答题界面点掉，等于每轮重新找入口。
        """
        for _ in range(_NORMALIZE_ATTEMPTS):
            img = self._handle.capture()
            self.last_image = img
            blocks = self._ocr.detect_text(img)
            if parse_question(blocks, img.shape[1]) is not None \
                    or detect_quiz(blocks):
                ctx.pop("fail_reason", None)
                return
            if self._matched("alliance_btn", img):
                ctx.pop("fail_reason", None)
                return
            if self._matched("net_error_confirm", img):
                self._click_net_error()
                continue
            if self._matched("form_title", img):
                self._handle.click(*_FORM_CLOSE_XY)
                continue
            if self._matched("war_title", img):
                self._handle.click(*_WAR_CLOSE_XY)
                continue
            if self._matched("queue_panel", img):
                self._handle.click(*_QUEUE_COLLAPSE_XY)
                continue
            if self._matched("map_btn", img):
                self._click("map_btn")
                continue
            self._sleep(self._pause(None))
        ctx["fail_reason"] = NORMALIZE_STUCK_REASON
        logger.warning("[答题] 归一化收拾不出地图或答题界面，本轮中止")

    def _matched(self, rec_id: str, img) -> bool:
        rec = self._rec.get(rec_id)
        return rec is not None and rec.recognize(img).matched

    # ---- NORMALIZE → OPEN_QUIZ ----

    def _reset_nav(self, ctx):
        self._nav_steps = 0
        ctx.pop("fail_reason", None)
        ctx["in_quiz"] = False

    def _open_quiz_step(self, ctx):
        """一拍导航：已经在答题界面就停；否则点入口文字，再不行点固定落点。

        `parse_question`（而不是 `detect_quiz`）才是「已进答题界面」的判据：
        活动页标题里也有「国士无双」，`detect_quiz` 在活动页就是 True。
        """
        ctx.pop("fail_reason", None)
        img = self._handle.capture()
        self.last_image = img
        blocks = self._ocr.detect_text(img)
        question = parse_question(blocks, img.shape[1])
        ctx["in_quiz"] = question is not None
        if question is not None:
            self._pending_question = question
            logger.info("[答题] 已在答题界面")
            return
        if self._nav_steps >= _NAV_MAX:
            ctx["fail_reason"] = QUIZ_ENTRY_MISSING_REASON
            logger.warning("[答题] 导航 %s 步仍未进入答题界面，本轮中止", _NAV_MAX)
            return
        entry = find_quiz_entry(blocks)
        if entry is not None:
            logger.info("[答题] 点入口 %s（第 %s 步）", entry, self._nav_steps + 1)
            self._click_xy(*entry, anchor="quiz_entry")
        elif self._nav_steps < len(self._entry_taps):
            x, y = self._entry_taps[self._nav_steps]
            logger.info("[答题] 点固定落点 (%s,%s)（第 %s 步）",
                        x, y, self._nav_steps + 1)
            self._click_xy(x, y, anchor="quiz_entry_tap")
        else:
            ctx["fail_reason"] = QUIZ_ENTRY_MISSING_REASON
            logger.warning("[答题] 屏幕上没有入口文字，也没有可用的固定落点"
                           "（config.quiz.entry_taps 为空或已用完），本轮中止")
            return
        self._nav_steps += 1
        self._wait_here("OPEN_QUIZ", _NAV_SETTLE)

    # ---- READ ----

    def _read(self, ctx):
        """读当前这一题。三种出口：作答、重读、收本轮/中止。"""
        ctx.pop("fail_reason", None)
        ctx.pop("round_over", None)
        ctx.pop("parse_verdict", None)
        ctx.pop("cooldown_why", None)
        if self._answered >= self._max_questions:
            ctx["round_over"] = True
            ctx["cooldown_why"] = f"已达单轮上限 {self._max_questions} 题"
            return
        img = self._handle.capture()
        self.last_image = img
        blocks = self._ocr.detect_text(img)
        question = parse_question(blocks, img.shape[1])
        if question is not None:
            if normalize(question.text) != self._answered_key:
                self._read_waits = 0
                self._pending_question = question
                logger.info("[答题] 第 %s 题：%s", self._answered + 1, question.text)
                return
            # 刚答过的那题还在屏幕上：等它翻页（有界）
            self._read_waits += 1
            if self._read_waits <= _ADVANCE_WAIT_MAX:
                ctx["parse_verdict"] = "retry"
                self._wait_here("READ", _ADVANCE_INTERVAL)
                return
            ctx["round_over"] = True
            ctx["cooldown_why"] = "同一题反复出现"
            return
        # 读不出题：先处理断网弹框，再重读；耗尽后区分「结束」与「异常」
        if self._matched("net_error_confirm", img):
            self._click_net_error()
            ctx["parse_verdict"] = "retry"
            self._wait_here("READ", _PARSE_INTERVAL)
            return
        self._read_waits += 1
        if self._read_waits < self._parse_retries:
            ctx["parse_verdict"] = "retry"
            self._wait_here("READ", _PARSE_INTERVAL)
            return
        on_quiz_screen = detect_quiz(blocks)
        at_map = self._matched("alliance_btn", img)
        if self._answered > 0 and (on_quiz_screen or at_map):
            ctx["round_over"] = True
            ctx["cooldown_why"] = ("活动页已无题" if on_quiz_screen
                                   else "已被送回地图")
            logger.info("[答题] 连续 %s 次读不出题目（%s），判本轮结束",
                        self._read_waits,
                        "仍在活动页" if on_quiz_screen else "已回到地图")
            return
        if self._answered > 0:
            ctx["fail_reason"] = QUIZ_SCREEN_LOST_REASON
            logger.warning("[答题] 连续 %s 次读不出题目，画面既不是答题页也不是"
                           "地图（弹窗/断线盖住了），本轮中止", self._read_waits)
            return
        ctx["fail_reason"] = QUIZ_PARSE_FAILED_REASON
        logger.warning("[答题] 连续 %s 次读不出题目，且本轮一题都没答过"
                       "（识别/分辨率/界面改版），本轮中止", self._read_waits)

    # ---- READ → ANSWER ----

    def _choose(self, ctx):
        ctx.pop("fail_reason", None)
        ctx.pop("semi_auto", None)
        question = self._pending_question
        if question is None:
            ctx["fail_reason"] = QUIZ_PARSE_FAILED_REASON
            logger.warning("[答题] 进入作答时没有待答题目（内部状态丢失），本轮中止")
            return
        decision = self._solver.answer(question)
        if decision is None:
            ctx["fail_reason"] = QUIZ_PARSE_FAILED_REASON
            logger.warning("[答题] 这道题没有可点的选项，本轮中止")
            return
        letter = decision.letter
        ctx["clicked_letter"] = letter
        ctx["answer_source"] = decision.source
        logger.info("[答题] %s → %s. %s（来源：%s）", question.text, letter,
                    decision.text, decision.source)
        if not self._auto_click:
            ctx["semi_auto"] = True
            ctx["cooldown_why"] = "auto_click=false，只给建议"
            return
        box = question.options[letter][1]
        self._click_xy(*box.center(), anchor="quiz_option")

    # ---- ANSWER → VERIFY ----

    def _verify(self, ctx):
        """答完等一会儿再截图：绿色高亮 = 正确答案。

        答错时所选项变红、正确项仍是绿，所以**答对答错都能学到答案**。
        没看到绿色只说明结算还没出来（或这题不会高亮），不算失败——
        「有没有翻页」由 ADVANCE 裁决。
        """
        ctx.pop("correct_letter", None)
        self._sleep(self._verify_delay)
        img = self._handle.capture()
        self.last_image = img
        question = self._pending_question
        if question is None:
            return
        boxes = {letter: box for letter, (_t, box) in question.options.items()}
        correct = pick_correct_option(img, boxes, min_ratio=self._min_green_ratio)
        if correct is None:
            logger.info("[答题] 没看到绿色高亮（结算可能还没出来），这道题不学习")
            return
        ctx["correct_letter"] = correct
        text = question.options[correct][0]
        if correct == ctx.get("clicked_letter"):
            logger.info("[答题] ✅ 答对（%s. %s）", correct, text)
        else:
            logger.info("[答题] ❌ 点的是 %s，绿色是 %s. %s",
                        ctx.get("clicked_letter"), correct, text)

    # ---- VERIFY → LEARN ----

    def _learn(self, ctx):
        question = self._pending_question
        if question is None:
            return
        correct = ctx.get("correct_letter")
        if correct is not None:
            answer = question.options[correct][0]
            if self._bank.learn(question.text, answer):
                logger.info("[答题] 已写入学习题库：%s → %s", question.text, answer)
        self._answered_key = normalize(question.text)
        self._answered += 1

    # ---- LEARN → ADVANCE ----

    def _advance(self, ctx):
        """等屏幕翻到下一题；始终不翻就判 `answer_not_accepted`（真失败）。"""
        ctx.pop("fail_reason", None)
        ctx.pop("next_question", None)
        ctx.pop("round_over", None)
        img = self._handle.capture()
        self.last_image = img
        blocks = self._ocr.detect_text(img)
        question = parse_question(blocks, img.shape[1])
        if question is not None and normalize(question.text) != self._answered_key:
            ctx["next_question"] = True
            self._pending_question = question
            return
        self._advance_waits += 1
        if self._advance_waits <= _ADVANCE_WAIT_MAX:
            self._wait_here("ADVANCE", _ADVANCE_INTERVAL)
            return
        if question is not None:
            ctx["fail_reason"] = ANSWER_NOT_ACCEPTED_REASON
            logger.warning("[答题] 点了选项 %s 后画面停在原题（%s 次），"
                           "这一票没被受理，本轮中止",
                           ctx.get("clicked_letter"), self._advance_waits)
            return
        ctx["round_over"] = True
        ctx["cooldown_why"] = "答完后答题界面已结束"
        logger.info("[答题] 答完后读不出下一题（%s 次），判本轮结束",
                    self._advance_waits)

    def _enter_next(self, ctx):
        self._read_waits = 0
        self._advance_waits = 0
```

```python
def create_quiz_state_machine(character, handle_source, recognizers, ocr, bank,
                              solver, *, verify_delay: float = 1.2,
                              min_green_ratio: float = 0.55,
                              max_questions_per_round: int = 30,
                              round_cooldown_min: float = 10.0,
                              parse_retries: int = 2, entry_taps=None,
                              auto_click: bool = True, human=None):
    """答题模式的状态机工厂。

    与宝石工厂并列而不是合并：答题的依赖比宝石多两个活对象（OCR 引擎、
    题库/求解器），而且它们**跨轮复用**（协调器建一次）。塞进
    `create_state_machine` 会让寨子那条路平白多两个必填参数。

    `event_bus` / `ledger` / `rally_tracker` 一个都不传：一台模拟器一个号，
    没有跨实例通信（spec §2）。
    """
    return QuizStateMachine(
        handle_source, ocr=ocr, bank=bank, solver=solver,
        recognizers=recognizers,
        verify_delay=verify_delay, min_green_ratio=min_green_ratio,
        max_questions_per_round=max_questions_per_round,
        round_cooldown_min=round_cooldown_min,
        parse_retries=parse_retries,
        entry_taps=[tuple(int(v) for v in tap) for tap in (entry_taps or [])],
        auto_click=auto_click, char_id=character.id, human=human)
```

```python
"""答题模式的协调器。

与宝石模式同一副骨架：一台模拟器一个号、各干各的，没有事件总线跨实例
路由、没有动作账本、没有车头/成员分工。

**跨轮复用的是活对象，不是状态机**（与寨子模式同一条原则）：
  * `QuizBank` —— 1076 条随包题库 + 学习库，读一次就够
  * OCR 引擎 —— 加载模型要好几秒
  * `Solver` —— 每次 start 重建一次（解包配置，很便宜）
SM 每轮由 `_sm_factory_for` 重建，见的都是这几个对象。
"""
from __future__ import annotations

from ..core.quiz.bank import QuizBank
from ..core.quiz.llm import LLMClient
from ..core.quiz.solver import Solver
from ..infra.app_paths import resolve_asset, user_dir
from ..infra.config import AppMode
from ..infra.logger import get_logger
from ..workers.factory import create_quiz_state_machine
from .base_runtime import BaseCoordinator

logger = get_logger(__name__)


def _default_bank() -> QuizBank:
    """随包题库只读、学习结果写 `user_dir()`（冻结后 exe 同级）。

    **两手都要用 app_paths**：相对路径按 CWD 解在绿色包里是错的
    （双击时 CWD 可能是 System32）。
    """
    return QuizBank(shipped_path=resolve_asset("templates/quiz/quiz_bank.json"),
                    learned_path=user_dir() / "quiz" / "learned.json")


def _llm_from_config(cfg) -> LLMClient | None:
    """没启用、或没填 Key → None（题库外的题直接随机，不发请求）。"""
    if not cfg.enabled or not cfg.api_key.strip():
        return None
    return LLMClient(base_url=cfg.base_url, model=cfg.model,
                     api_key=cfg.api_key, timeout_s=cfg.timeout_s)


class QuizCoordinator(BaseCoordinator):
    def __init__(self, config, event_bus=None, template_dir=None, *,
                 ocr=None, bank_factory=None):
        super().__init__(config, event_bus=event_bus,
                         template_dir=template_dir)
        self._ocr = ocr
        self._bank_factory = bank_factory or _default_bank
        self._bank: QuizBank | None = None
        self._solver: Solver | None = None

    def _instances(self):
        return self._config.instances_for(AppMode.QUIZ)

    def _pre_start(self, instances) -> None:
        if self._bank is None:
            self._bank = self._bank_factory()
            self._bank.load()
            logger.info("[答题] 题库已加载：%s 条（随包 + 学习）",
                        self._bank.size)
        if self._ocr is None:
            # 延迟 import：加载 onnxruntime 要好几秒，模块导入时不该付这笔钱
            from ..core.recognizers.ocr_text import RapidOcrEngine
            self._ocr = RapidOcrEngine()
        llm = _llm_from_config(self._config.quiz.llm)
        logger.info("[答题] 大模型兜底：%s", "已启用" if llm else "未启用")
        self._solver = Solver(self._bank, llm,
                              fuzzy_threshold=self._config.quiz.fuzzy_threshold)

    def _sm_factory_for(self, char, handle, recognizers, profile):
        quiz = self._config.quiz
        return create_quiz_state_machine(
            char, handle, recognizers, self._ocr, self._bank, self._solver,
            verify_delay=quiz.verify_delay,
            min_green_ratio=quiz.min_green_ratio,
            max_questions_per_round=quiz.max_questions_per_round,
            round_cooldown_min=quiz.round_cooldown_min,
            parse_retries=quiz.parse_retries,
            entry_taps=quiz.entry_taps,
            auto_click=quiz.auto_click,
            human=profile)

    def _max_rounds(self) -> int:
        """`quiz.max_rounds`，**不是** `app.max_rounds`（spec §5）。"""
        return self._config.quiz.max_rounds
```

```python
def _imread(path: Path) -> np.ndarray:
    """读图：Windows 上 `cv2.imread` 读不了中文路径，先按字节读再解码。"""
    data = np.fromfile(str(path), dtype=np.uint8)
    frame = cv2.imdecode(data, cv2.IMREAD_COLOR)
    if frame is None:
        raise SystemExit(f"读不出素材：{path}")
    return frame


def _sample_video(path: Path, seconds: float) -> np.ndarray:
    cap = cv2.VideoCapture(str(path))
    try:
        cap.set(cv2.CAP_PROP_POS_MSEC, seconds * 1000.0)
        ok, frame = cap.read()
    finally:
        cap.release()
    if not ok or frame is None:
        raise SystemExit(f"视频抽帧失败：{path} @{seconds}s")
    return frame


class _Report:
    """PASS / FAIL / SKIP 三态计数。FAIL 决定退出码。"""

    def __init__(self):
        self.fails = 0
        self.passes = 0
        self.skips = 0

    def check(self, ok: bool, name: str, detail: str = "") -> bool:
        tag = "PASS" if ok else "FAIL"
        if ok:
            self.passes += 1
        else:
            self.fails += 1
        print(f"{tag}  {name}" + (f"  —— {detail}" if detail else ""))
        return ok

    def skip(self, name: str, detail: str = "") -> None:
        self.skips += 1
        print(f"SKIP  {name}" + (f"  —— {detail}" if detail else ""))

    def summary(self) -> None:
        print(f"\n合计：{self.passes} PASS / {self.fails} FAIL / "
              f"{self.skips} SKIP")


def _letter_holding(question, marker: str) -> str | None:
    """选项文本里含 `marker` 的那个字母。"""
    for letter, text in question.option_texts().items():
        if marker in text:
            return letter
    return None

                  learned_path: Path) -> None:
    # ---- 正常习题帧：四选项 + 提示语/按钮不进候选池 ----
    key, seconds = _PRACTICE_FRAME
    path = found.get(key)
    if path is None:
        rep.skip("习题帧", "素材缺失")
    else:
        frame = _sample_video(path, seconds)
        blocks = engine.detect_text(frame)
        q = parse_question(blocks, frame.shape[1])
        if q is None:
            rep.check(False, "习题帧解析", f"{key}@{seconds}s 认不出 4 个选项")
        else:
            texts = " ".join(q.option_texts().values())
            bad = [w for w in ("求助", "放弃", "机会") if w in texts]
            rep.check(not bad, "提示语/按钮不进选项池",
                      f"4 个选项，误入 {bad}" if bad else
                      " / ".join(q.option_texts().values()))

    # ---- 绿色高亮：判到同一个字母，其余全判否 ----
    for key, seconds, marker in _VERIFY_MARKS:
        path = found.get(key)
        if path is None:
            rep.skip(f"{key}@{seconds}s", "素材缺失")
            continue
        frame = _sample_video(path, seconds)
        blocks = engine.detect_text(frame)
        q = parse_question(blocks, frame.shape[1])
        if q is None:
            rep.check(False, f"{key}@{seconds}s 解析", "认不出 4 个选项")
            continue
        want = _letter_holding(q, marker)
        if want is None:
            rep.check(False, f"{key}@{seconds}s 定位绿块",
                      f"没有选项含「{marker}」")
            continue
        boxes = {k: v[1] for k, v in q.options.items()}
        got = pick_correct_option(frame, boxes, min_ratio=MIN_GREEN)
        ratios = {k: round(green_ratio(frame, b), 2) for k, b in boxes.items()}
        rep.check(got == want, f"{key}@{seconds}s 绿色判定",
                  f"期望 {want}「{marker}」，得到 {got}；绿占比 {ratios}")
        others = [k for k in boxes if k != want]
        rep.check(all(ratios[k] < MIN_GREEN for k in others),
                  f"{key}@{seconds}s 其余选项全判否",
                  f"{ {k: ratios[k] for k in others} }")

    # ---- 只 OCR 出 3 个选项：期望解析失败（→ SM 原地重试） ----
    key, seconds = _PARSE_FAIL_FRAME
    path = found.get(key)
    if path is None:
        rep.skip("3 选项帧", "素材缺失")
    else:
        frame = _sample_video(path, seconds)
        blocks = engine.detect_text(frame)
        q = parse_question(blocks, frame.shape[1])
        rep.check(q is None, f"{key}@{seconds}s 3 个选项必须解析失败",
                  f"得到 {None if q is None else q.option_texts()}")

    # ---- 学习：新题写盘、随包答案不被覆盖 ----
    key, seconds, _marker = _VERIFY_MARKS[0]
    path = found.get(key)
    if path is None:
        rep.skip("学习", "素材缺失")
        return
    frame = _sample_video(path, seconds)
    blocks = engine.detect_text(frame)
    q = parse_question(blocks, frame.shape[1])
    if q is None:
        rep.skip("学习", "该帧解析失败")
        return
    boxes = {k: v[1] for k, v in q.options.items()}
    correct = pick_correct_option(frame, boxes, min_ratio=MIN_GREEN)
    # 学「绿的那个选项」；没判出绿色就退到第一个选项——这里验的是写盘链路，
    # 不是答案对不对（绿色判定在上面的 verify 段已经单独断言过）。
    answer = q.options[correct][0] if correct is not None \
        else next(iter(q.option_texts().values()))
    probe = q.text + "（验收探针）"          # 保证是题库里没有的新题
    shipped_before = BANK_PATH.read_bytes()
    rep.check(bank.learn(probe, answer), "learn 写入新题", probe)
    rep.check(BANK_PATH.read_bytes() == shipped_before, "learn 不碰随包题库")
    entries = json.loads(learned_path.read_text(encoding="utf-8"))
    rep.check(any(e.get("a") == answer for e in entries),
              "learned.json 读得回来", f"{len(entries)} 条")
    rep.check(bank.learn("统帅贝利撒留的昵称是？", "错误答案") is False,
              "learn 不覆盖随包答案")


def main(argv: list[str] | None = None) -> int:
    args = list(sys.argv[1:] if argv is None else argv)
    if len(args) > 1:
        print("用法：tools/quiz_acceptance.py [素材目录]")
        return 2
    root = Path(args[0]) if args else DEFAULT_MATERIALS

    rep = _Report()
    found = index_materials(root)
    if not found:
        rep.skip("素材", f"{root} 不存在或没有素材 —— SKIP（dati/ 不入库）")
        rep.summary()
        return 0
    if not BANK_PATH.is_file():
        print(f"随包题库不存在：{BANK_PATH}（先做 Task 2）")
        return 1

    engine = RapidOcrEngine()
    with tempfile.TemporaryDirectory() as tmp:
        learned = Path(tmp) / "learned.json"
        bank = QuizBank(BANK_PATH, learned)
        bank.load()
        # 固定种子：随机兜底不联网、可复现；LLM 一律不接（验收不许发请求）
        solver = Solver(bank, None, rng=random.Random(20261024))
        _check_stills(found, engine, solver, rep)
        _check_videos(found, engine, rep, bank, learned)
    rep.summary()
    return 1 if rep.fails else 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
# -*- coding: utf-8 -*-
"""真机入口探针：一步步探「地图 → 活动页 → 习题演练」到底点哪里。

用法:
  $PY -X utf8 tools/quiz_entry_probe.py [--instance <实例id>] [--tap X,Y ...] [--save out.png]

不传 `--tap` 就只截一帧、打印 OCR 块与入口候选；每个 `--tap` 会先点那个坐标
再重新截图，逐帧打印。最后打印 `find_quiz_entry()` 的结论，以及一行可以直接
粘进 `config.yaml` 的 `entry_taps`。

为什么要有它：`dati/test/` 的素材都**从活动页开始**，地图那一步没有素材
（spec §10 已知局限 4）。入口路径只能真机探——**别在计划里臆造坐标**。
"""
from __future__ import annotations

import sys
import time
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT / "src"))

import cv2                                                          # noqa: E402
import numpy as np                                                  # noqa: E402

from rok_assistant.core.handle_source import create_handle_source    # noqa: E402
from rok_assistant.core.quiz.screen import (                         # noqa: E402
    detect_quiz, find_quiz_entry, parse_question)
from rok_assistant.core.recognizers.ocr_text import RapidOcrEngine   # noqa: E402
from rok_assistant.infra.app_paths import config_path                # noqa: E402
from rok_assistant.infra.config import load_config                    # noqa: E402

MAX_BLOCKS = 60


def _parse_tap(text: str) -> tuple[int, int]:
    x, y = text.split(",", 1)
    return int(x), int(y)


def _dump(frame, engine, taps: list[tuple[int, int]]) -> list:
    """打印一帧的 OCR 块与三种判据；返回 blocks 供调用方复用（OCR 很贵）。"""
    h, w = frame.shape[:2]
    blocks = engine.detect_text(frame)
    print(f"\n=== {w}x{h}  {len(blocks)} 块"
          f"  已点：{taps or '（无）'}")
    rows = sorted((box.y1, box.x1, text, conf, box) for box, text, conf in blocks)
    for i, (_y, _x, text, conf, box) in enumerate(rows):
        if i >= MAX_BLOCKS:
            print(f"    ... 还有 {len(rows) - MAX_BLOCKS} 块")
            break
        print(f"  y={box.y1:4d} x={box.x1:4d} c={conf:.2f} | {text[:40]}")
    print(f"  detect_quiz={detect_quiz(blocks)}"
          f"  parse={'有题目' if parse_question(blocks, w) else '无'}"
          f"  entry={find_quiz_entry(blocks)}")
    return blocks


def main(argv: list[str] | None = None) -> int:
    args = list(sys.argv[1:] if argv is None else argv)
    instance_id = None
    taps: list[tuple[int, int]] = []
    save = None
    i = 0
    while i < len(args):
        if args[i] == "--instance" and i + 1 < len(args):
            instance_id = args[i + 1]
            i += 2
        elif args[i] == "--tap" and i + 1 < len(args):
            taps.append(_parse_tap(args[i + 1]))
            i += 2
        elif args[i] == "--save" and i + 1 < len(args):
            save = Path(args[i + 1])
            i += 2
        else:
            print(f"未知参数：{args[i]}")
            return 2

    cfg_file = config_path()
    if not cfg_file.is_file():
        print(f"找不到配置文件：{cfg_file}（先运行一次程序，它会生成 config.yaml）")
        return 1
    cfg = load_config(cfg_file)
    instances = list(cfg.quiz.instances)
    if not instances:
        print("config.yaml 的 quiz.instances 是空的——先填一台模拟器再探。")
        return 1
    inst = next((x for x in instances if x.id == instance_id), None) \
        if instance_id else instances[0]
    if inst is None:
        print(f"quiz.instances 里没有 id={instance_id}")
        return 1

    engine = RapidOcrEngine()
    app = cfg.app
    handle = create_handle_source(
        mumu_index=inst.mumu_index,
        mumu_manager_path=app.mumu_manager_path,
        adb_address=inst.adb_address,
        adb_path=app.adb_path,
        window_title_pattern=inst.window_title_pattern)
    print(f"[探针] 实例「{inst.name or inst.id}」——请先手动把号停在地图视图。")

    for tap in taps:
        print(f"[探针] 点击 {tap}")
        handle.click(tap[0], tap[1])
        time.sleep(1.5)                  # 等界面动画落定，否则截到的是过渡帧
    frame = handle.capture()
    blocks = _dump(frame, engine, taps)
    if save is not None:
        # cv2.imwrite 同样读不了中文路径，按扩展名编码再写字节
        ok, buf = cv2.imencode(save.suffix or ".png", frame)
        if ok:
            save.write_bytes(buf.tobytes())
            print(f"[探针] 已保存 {save}")

    entry = find_quiz_entry(blocks)
    if entry is None:
        print("\n没有找到入口文字。把号停在活动页再跑一次，"
              "或用 --tap 逐步试出路径，再把点过的坐标填进 entry_taps。")
    else:
        print(f"\n推荐点击点：{entry[0]},{entry[1]}")
    pts = ", ".join(f"[{x}, {y}]" for x, y in taps)
    print("探完把**确实点进去过**的坐标按顺序填进 config.yaml：")
    print(f"  quiz:\n    entry_taps: [{pts}]")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
