# 实施计划：答题模式移除「运行轮次 / 轮间冷却」配置

> 用户 2026-10-25 拍板：「答题模式下的运行轮次和冷却时间的配置请移除，因为一天
> 只能答一次，无法重复答」。只动答题（quiz）段；寨多多/宝石/公共段的轮次配置
> 不动（那些模式本来就能反复跑）。

## 设计结论

一天只能答一次 ⇒ 「跑几轮、两轮等多久」两个旋钮失去意义。移除配置的同时，
把支撑它们的机制一并收口，避免留死代码：

| 层 | 改动 |
|---|---|
| `infra/config.py` `QuizConfig` | 删 `max_rounds` / `round_cooldown_min` 两个字段 |
| `workers/quiz_sm.py` | 删 `round_cooldown_min` 参数与 `_cooldown_min`；**删 COOLDOWN 状态**——`round_over` / `semi_auto` 三条边直通 END，边上的动作 `_enter_cooldown` → `_end_round`（只打「本轮结束（答了 N 题）：原因」日志，不再 `_wait_here`）；ctx 键 `cooldown_why` → `round_end_why` |
| `workers/factory.py` | 工厂删 `round_cooldown_min` 形参 |
| `coordination/quiz_runtime.py` | SM 工厂调用去掉该实参；`_max_rounds()` 恒返回 **1**（docstring 说明：一天只能答一次，与 `app.max_rounds` 无关） |
| `gui/config_dialog.py` | 答题页删两行输入框；新增「一天一轮」提示 Label（objectName=`oneRoundHint`） |
| `gui/labels.py` | 删 `round_cooldown_min` 标签映射（`max_rounds` 映射保留——公共段还在用） |
| `config.example.yaml` | quiz 段删两个键，加一行注释说明一天一轮 |

**行为后果**（符合用户意图）：runner `_check_stop_conditions` 在冷却休眠**之前**
break，所以答题跑满 1 轮即收工，不会白等 runner 的 30s；环境类中止（找不到入口等）
同样一轮即收工。pydantic 默认 `extra=ignore`，旧 config.yaml 残留两个键不影响加载。

runner / labels 里的 COOLDOWN 通用映射保留（gem 等模式可能用，test_labels 钉着）。
