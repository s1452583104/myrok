## 打寨子特定规则（来自用户）

- 目标：国内地图 1-10 级野蛮人城寨，常规 6-10 级
- 入口：游戏**内置「搜索指定等级寨子」**——不用助手在地图上找，是 UI 里有搜索按钮
- 一个寨子**只能被一个集结锁定**
- 点集结时**可能弹出"已被其他成员发起集结"提示**——助手必须能识别并跳过
- 倒计时结束人没满 → 集结自动解散 → 车头重发

### 角色切换流程 ✅（4 层深路径）
1. 主界面左上角头像（带名字）→ 点击
2. 「执政官资料」弹窗 → 点击「**设置**」按钮（右下）
3. 「设置」弹窗 → 点击「**角色管理**」按钮（中排左二）
4. 「角色管理」弹窗 → 列「星标角色」，点击目标角色头像
- **用户当前角色**带绿色 ✅
- 普通角色在底部折叠区「普通角色」（本项目不关注）
- **调度影响**：每次切换角色需要 4 次点击 + 切到新角色后的加载等待
- 资源路径必须稳定：头像位置 / 设置位置 / 角色管理位置 / 每个角色头像位置（OCR 读名字匹配）

### 成员「加入集结」流程 ✅
1. 切到 member character（走上面 4 步路径）
2. 主界面 → 点「联盟」按钮（底部主菜单）
3. 联盟界面 → 点「战争」按钮（左上第一格）
4. 战争界面 → 把「最新发起」改成「距离最近」排序
5. 从 rally 列表选：
   - 策略=nearest：选第一个
   - 策略=leaders：选第一个发起人匹配列表的（OCR 名字匹配）
6. 点「+」加入 → 进入「组建部队」弹窗（同车头）
7. 选 preset / 选兵种 → 行军
