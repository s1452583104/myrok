# 企业级界面重构 —— 设计

> 日期：2026-10-13　状态：已实现
> 前置：`docs/superpowers/specs/2026-09-09-config-multi-instance-gui-design.md`（GUI 骨架）
> 相关：`docs/配置说明.md`（**随绿色包分发，界面文案变了必须同步**）

## 1. 目标与由来

界面从「作者自用脚本」长成了**随绿色包分发给非程序员**的工具（`docs/配置说明.md`
就是写给他们的），但视觉层从没立过规范：全仓库 `setStyleSheet` 只有 5 处，且都是
临时补丁——`character_card.py` 的 `background:#500`、`main_window.py` 的 `color:#27ae60`
/ `#c0392b`、`config_dialog.py` 的裸 `red`。同一件「错误」在不同文件里是三种红。

本次按企业级 B 端规范（对标 Ant Design 5 / 华为云控制台）重做视觉层，目标是：

1. **色值/间距/字号有唯一出处**，控件里不再写死；
2. **主次分明**：一个操作区里主按钮唯一；
3. **文案统一中文**（卡片早就中文化了，顶栏却还是 `Start` / `Stop` / `Mode`）。

**业务零改动**：`infra/`、`core/`、`workers/`、`coordination/`、`_run_goal.py` 一行不碰。
无头驱动不经过 GUI，本次改动对它零影响。

## 2. 两条已定决策

| 决策点 | 选择 | 影响 |
|---|---|---|
| 重构深度 | **完整重构** | 新增令牌层 + 全局 QSS；主窗口改四段式布局；卡片/弹窗统一容器与按钮层级 |
| 文案语言 | **统一中文** | `Start`→「开始运行」、`Stop`→「停止」、`Mode`→「模式」、窗口标题→「RoK 助手」 |

## 3. 架构：令牌先行 → 主题层统一上色 → 再动结构

```
gui/theme.py          设计令牌（间距/圆角/字号/色板）+ 全局 QSS + apply_theme()
      ↓ 被所有界面 import
gui/labels.py         语义映射（state_label 中文 / state_kind 语义）——不给色值
gui/flow_layout.py    卡片区自适应流式布局
gui/main_window.py    应用头 / 操作栏 / 卡片网格 / 状态栏
gui/character_card.py 卡片容器 + 状态标签 + 缩略图 + 日志
gui/config_dialog.py  树 / 表 / 表单 / 页内滚动 / 底部按钮栏
gui/license_dialog.py 标题区 + 表单 + 按钮层级
```

### 3.1 为什么令牌与语义分家

`labels.py` 只回答「这个状态是好是坏」（`success / info / warning / error / default`），
`theme.py` 只回答「这个语义长什么样」。合成一处的话，加一个状态就得同时改配色，
改配色又得翻状态表——两边都会漂。分开之后新增状态只需要在 `STATE_KINDS` 加一行。

### 3.2 为什么用 `string.Template` 而不是 f-string

CSS 里满是 `{}`，f-string 要逐个转义成 `{{}}`，改一行 CSS 得数括号。`Template` 用
`$TOKEN` 占位，且 `substitute()` 在缺令牌时**抛 KeyError**——这次重构真踩到了
（`$sp_xs` / `$sp_2xl` 用了但没进令牌表），如果当初用 `safe_substitute()` 就会静默
留下一堆 `$sp_xs` 字面量在样式表里，界面不报错但间距全丢。
`tests/unit/gui/test_theme.py` 双向对账（用了没定义 / 定义了没用）把这条路封死。

### 3.3 必须先切 Fusion

`apply_theme()` 第一件事是 `app.setStyle("Fusion")`。Windows 默认的 `windowsvista`
样式会**忽略 QComboBox / QSpinBox / QTableWidget 的大量 QSS 属性**，不切样式表刷不齐。
`apply_theme` 还必须在**创建任何控件之前**调用——QSS 在 polish 时读动态属性，
控件先建好再上样式，`QPushButton[primary="true"]` 这类选择器不生效。

## 4. 设计令牌

| 维度 | 令牌 | 值 |
|---|---|---|
| 间距 | `SP_XS/SM/MD/LG/XL/2XL` | 4 / 8 / 12 / 16 / 24 / 32 |
| 圆角 | `RADIUS_SM/MD/CONTROL/CARD` | 2 / 4 / 6 / 8 |
| 字号 | `FONT_SIZE_CAPTION/BODY/SUBTITLE/TITLE` | 12 / 14 / 16 / 20 |
| 品牌色 | `PRIMARY / HOVER / ACTIVE` | `#1677FF` / `#4096FF` / `#0958D9` |
| 功能色 | `SUCCESS / WARNING / ERROR` | `#52C41A` / `#FAAD14` / `#FF4D4F` |
| 中性 | `TEXT_PRIMARY/SECONDARY/TERTIARY/DISABLED` | `#1F1F1F` / `#595959` / `#8C8C8C` / `#BFBFBF` |
| 背景 | `BG_LAYOUT / BG_CONTAINER / BG_HEADER` | `#F0F2F5` / `#FFFFFF` / `#FAFAFA` |
| 分割 | `BORDER_BASE / BORDER_SPLIT` | `#D9D9D9` / `#F0F0F0` |

两条落成实色而非令牌原文 `rgba(0,0,0,0.88)` 的理由：Qt QSS 对 rgba 浮点 alpha 的解析
各版本不一致，实色十六进制是白底上的等价值，行为确定。

**状态标签**统一「浅底 + 深字 + 同色点」，圆角 2、字号 12：

| 语义 | 底 | 字 | 点 |
|---|---|---|---|
| success | `#F6FFED` | `#389E0D` | `#52C41A` |
| info | `#E6F4FF` | `#0958D9` | `#1677FF` |
| warning | `#FFFBE6` | `#D48806` | `#FAAD14` |
| error | `#FFF1F0` | `#CF1322` | `#FF4D4F` |
| default | `#F5F5F5` | `#595959` | `#BFBFBF` |

**按钮层级**：默认次按钮（白底灰描边）／`[primary="true"]` 主按钮（主色填充，
每屏 ≤ 1 个）／`[dashed="true"]` 虚线（添加类弱操作）／`[danger="true"]` 危险（删除）。
标记走 `theme.make_primary()` 等函数，内部 `setProperty` + `unpolish/polish`——
QSS 在 polish 时读属性，只设属性不重刷样式不生效。

## 6. Qt QSS 踩过的坑（写下来免得再踩）

1. **QSS 不支持 `box-shadow`**。规范本身也要求「列表页/表单页优先用 1px 分割线分区，
   不加阴影」，故一律用描边 + 留白，不引入 `QGraphicsDropShadowEffect`。
2. **`::down-arrow` 只认 `image:`**。照抄 CSS 的「0 尺寸盒子 + 三边透明边框」三角画法
   渲染出来是个**实心方块**。
3. **只给 `::drop-down` 描边会让箭头整个消失**——`QStyleSheetStyle` 一旦接管这个子控件，
   就不再用基础样式的箭头图元。最终**一条 `::drop-down` / `::down-arrow` 规则都不给**，
   代价是 Fusion 会画一道淡淡的下拉按钮分隔线，比丢箭头划算。
4. **别碰 `QCheckBox::indicator`**：接管了却不给 `image:`，未勾选的框会整个消失。
5. **`QApplication.style()` 装了样式表后返回的是 `QStyleSheetStyle` 代理**
   （`objectName` 为空、没有 `baseStyle()`）。要读基础样式得先把样式表清掉
   ——`test_theme.py` 里就这么干的，读完再装回去。
6. **全局 `QWidget { font-family }` 会盖掉控件自己的 `setFont()`**——样式表的字体
   属性优先于控件字体，`setFont` 静默失效、不报错。本次重构真踩到：激活对话框里
   机器码/激活码的等宽字体被刷回了雅黑（等宽的意义就是让 `O/0`、`I/l` 分得开，
   机器码要用户手抄）。修法是 `theme.make_mono(widget)`——打 `objectName="monoText"`，
   由 QSS 用 `#monoText`（比 `QWidget` 更具体）把族钉回去；**字号仍由 `setFont` 给**
   （QSS 不设 `font-size`，就沿用控件字体）。`test_mono_text_actually_renders_monospace`
   走完整链路（装主题 → 建控件 → 读回字体）钉住它——只断言「打了标记」是不够的，
   选择器写错时那条测试照样绿。
